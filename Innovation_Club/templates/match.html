Team Matcher

Matched by skill fit, not by who applied first

Every applicant is matched to an open project using a stable matching algorithm — the same class of algorithm used for medical residency placements. No pair of applicant and project would rather be with each other than with their current match.

How this works

Each applicant's skills are compared against each open project's needed skills using Jaccard similarity (overlap ÷ union). Applicants then "propose" to their best-scoring project in order of preference; a project holds its best-scoring applicants up to its open capacity and bumps a weaker one if a better fit proposes later. This is the Hospitals/Residents algorithm, a generalization of Gale–Shapley (1962) to many-to-one matching. Runs in roughly O(n · p) time for n applicants and p projects.
